# eROY prototype (demo)

A design prototype exploring improvements to a youth organisation registration website:
step-by-step guide, eligibility check, document pre-check, status tracker, FAQ and BM/EN switch.

**This is not an official site and is not affiliated with KBS or ROY.** Organisation names and statuses are fictional.
Login and sign-up fields are disabled. AI features (assistant, smart search, form check) need the local
server and do not work on this static copy.
